## Sobre mim

Sou estudante de Engenharia de Software na Universidade de Mogi das Cruzes (UMC) e estagiário de PCP na Paramount Têxteis, onde acompanho o planejamento da produção de uma indústria no dia a dia.

Foi nessa convivência com processos, prazos e rotinas de empresas que nasceu minha vontade de programar: quero construir software que resolva problemas reais de negócio. Hoje desenvolvo front-end com HTML, CSS e JavaScript, estudo back-end com Java e Python e dou os primeiros passos em mobile com Dart e Flutter.

Estou em busca de um estágio em desenvolvimento de software.
